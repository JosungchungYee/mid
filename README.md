# 돌려돌려 룰렛

고민되는 후보를 입력하고 Canvas 2D 룰렛을 돌려 무작위로 선택하는 반응형 웹앱입니다.

## 실행

`index.html`을 브라우저에서 열면 바로 사용할 수 있습니다. 별도 빌드 도구나 프레임워크는 필요하지 않습니다.

## 기능

- 가중치와 색상을 설정할 수 있는 룰렛 항목 편집
- 점심 메뉴, 간식, 벌칙 기본 프리셋과 프리셋 추가·삭제
- 사용자 항목과 프리셋을 브라우저 로컬 스토리지에 저장
- 모바일 화면을 고려한 반응형 레이아웃

## GitHub Pages 배포

저장소의 **Settings → Pages → Build and deployment → Source**에서 **GitHub Actions**를 선택하면 `main` 브랜치에 푸시할 때 자동으로 배포됩니다.
